# rtwKit

rtwKit contains the standard extension packages for
[Rintawa](https://github.com/martrtr/rintawa). Each package can be built and
released independently as an immutable `.rtw` artifact.

## Packages

| Directory | Package |
| --- | --- |
| [package-manager](packages/package-manager) | Discover, install and manage RTW packages |
| [web-runtime](packages/web-runtime) | Execution runtime for packaged web components |
| [web-ui](packages/web-ui) | Standard web interface and Portable UI renderer |
| [world-manager](packages/world-manager) | Browse, create and open Worlds |
| [character-library](packages/character-library) | Store and import character templates |
| [chat](packages/chat) | Persistent World conversations |

See the individual package directories for implementation details and build commands.

## Package distribution

Tagged package releases publish a versioned `.rtw` artifact to GitHub Releases.
The registry index is published on GitHub Pages:

https://martrtr.github.io/rtwKit/index.json

Package metadata, release digests and download URLs are generated by the registry
tooling. Source directories are independent of the versioned artifacts installed
by the Rintawa Host.

## Development

The repository uses Rust 1.98.1, with additional tooling as required by individual
packages. Use the package's own build instructions and run repository checks before
submitting changes.

```sh
bash scripts/check.sh
```

See [packages/README.md](packages/README.md) for package metadata and the release
tag format (`pkg-<slug>-v<version>`).
