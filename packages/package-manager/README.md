# Package Manager

Repository-backed RTW package management for Rintawa.

- Browse and search one or more HTTPS package repositories.
- Install exact package versions, resolve dependencies and review permissions.
- Update, enable, disable or uninstall packages with dependency checks.
- Install directly from a validated HTTPS `.rtw` URL.
- Save repository settings in owner-scoped preferences.

The default package repository is
https://martrtr.github.io/rtwKit/index.json.
